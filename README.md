
# Fun Store

![screenshot](https://funstore.tejasvaij.com/funstore.png)

[Demo Link ( funstore.tejasvaij.com )](https://funstore.tejasvaij.com/)

## Features

- **Search Functionality**: Allows users to search for products by entering a search query.
- **Category Filtering**: Enables filtering products based on selected categories.
- **Sorting Options**: Provides the ability to sort products by criteria such as price, rating, etc.
- **Cart Management**: Includes features for adding, removing, and updating quantities of items in the cart.
- **Order Summary**: Displays a detailed breakdown of the total cost, including delivery charges and taxes.

## Setup Instructions

### Prerequisites

- Node.js (v16 or later)
- npm or pnpm package manager
- A modern browser for testing the frontend

### Installation Steps

1. **Clone the Repository**:
   ```bash
   git clone git@github.com:TechManTejas/QED42_Wed_Dev_Assignment.git
   cd QED42_Wed_Dev_Assignment
   ```

2. **Install Dependencies**:
   Using npm:
   ```bash
   npm install
   ```
   Or using pnpm:
   ```bash
   pnpm install
   ```

3. **Set Up Environment Variables**:
   Rename the .env.example file to .env

4. **Run the Application**:
   Start the development server:
   ```bash
   npm dev
   ```
   Or using pnpm:
   ```bash
   pnpm dev
   ```

5. **Build for Production**:
   Create an optimized production build:
   ```bash
   npm run build
   ```
   Or using pnpm:
   ```bash
   pnpm run build
   ```


## How to Use

1. **Search for Products**:
   - Enter a keyword in the search bar to find relevant products.
2. **Filter by Category**:
   - Select a category from the dropdown to filter displayed products.
3. **Sort Products**:
   - Choose a sorting option to reorder the product list.
4. **Manage Your Cart**:
   - Add products to your cart, adjust quantities, or remove them.
5. **Checkout**:
   - Review the order summary and proceed to checkout when ready.
